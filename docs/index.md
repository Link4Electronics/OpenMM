# Installation

1. Download the [**Latest Version**](https://github.com/0x1F9F1/OpenMM/releases/download/build/OpenMM.zip) and extract the files directly into your MM1 directory. \
   For a fresh installation, only audio.ar, core.ar, and ui.ar are required from the original game.
2. Read the [**README**](./setup.md)
3. To play, run **OpenMM.exe**

# FAQ

* Do I need to install the XP patch?
    * No, OpenMM uses a separate executable.
* Do I need to install dgVoodoo2?
    * No, OpenMM uses an OpenGL renderer.
* What does OpenMM change?
    * See a list of changes [here](./changes.md).
* How do I work with the OpenMM code?
